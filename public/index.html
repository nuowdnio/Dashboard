        🌤 Wetter-Ort

          ✅ Todoist

          Standard: überfällige und die der nächsten 7 Tage. Beispiele: today | overdue, overdue | 7 days | p1, #Privat & 14 days. Die Filter bitte in englischer Schreibweise eingeben.

          📦 DHL-Sendungsstatus (optional)

          Ohne Schlüssel gibt es für jedes Paket einen Link zur Sendungsverfolgung. Mit einem kostenlosen DHL-API-Schlüssel aktualisiert das Dashboard den Status von DHL-Paketen automatisch. Den Schlüssel bekommst du auf developer.dhl.com → Konto anlegen → App erstellen → API „Shipment Tracking – Unified“.

          ✉️ E-Mail (GMX)

          Anderer Mailserver (optional)

          Vorher in GMX einmalig erlauben: E-Mail → Einstellungen → POP3/IMAP Abruf → „E-Mails über externe Programme senden und empfangen“. Bei Zwei-Faktor-Anmeldung ein App-Passwort verwenden. Das Dashboard zeigt ungelesene und markierte Mails und legt aus Versandmails automatisch Pakete an.
